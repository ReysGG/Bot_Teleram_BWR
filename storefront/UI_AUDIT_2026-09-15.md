## Temuan yang direproduksi

### P1 — Detail produk melebar dan terpotong di mobile

- Buka `/products/chatgpt-business-1-bulan-mt6n305e` pada 390 px atau 320 px.
- Pada 390 px, `.product-detail-copy` dan `.product-detail-art` mempunyai lebar
  sekitar 533 px dan sisi kanan sekitar 549 px. Judul, deskripsi, dan area aksi
  terpotong. `overflow-x: clip` pada dokumen menyembunyikan overflow sehingga
  scrollWidth dokumen saja tidak dapat mendeteksi bug ini.
- CSS terkait: `src/app/globals.css:419`, `:712`, `:713`, `:778`.
- Grid mobile memakai `1fr` dengan ukuran minimum intrinsik; gambar detail
  mempunyai aspect ratio 16:9 dan minimum tinggi 300 px. Minimum tinggi ini
  dapat memaksa lebar sekitar 533 px. Anak grid juga belum mempunyai min-width 0.
- Perbaikan: gunakan `minmax(0, 1fr)`, min-width 0 pada anak grid, hilangkan
  minimum tinggi gambar yang bertentangan dengan aspect ratio di HP, dan izinkan
  teks/URL panjang membungkus. Verifikasi tombol dan gambar di 320/390/768 px.

### P1 — Filter kategori hilang setelah pencarian atau pengurutan

## Klarifikasi sinkronisasi katalog

`src/lib/catalog-model.ts:206-210` menggunakan cache katalog server dengan
revalidate 60 detik. Data berasal dari API production, tetapi bukan push real-time
ke browser yang sedang terbuka. Interval ini bukan jaminan keterlambatan maksimum;
revalidation bergantung pada request dan dapat menyajikan cache lama sementara
refresh berlangsung. Jangan menjanjikan perubahan stok seketika tanpa reload.
